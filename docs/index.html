A FEW USEFUL DETAILS

Before you begin.

Can I use this for a commercial production?

Yes. The framework is MIT licensed, allowing commercial use and modification with the license notice retained. Reference images and other content you add have their own ownership and usage rights.

Do I need an AI account?

No API account is needed to organize, compare, and approve your existing images. Optional image generation requires your own OpenAI API key and is billed to your account. Generated work still needs an explicit approval.

Is this a cloud service or a Mac app?

The workspace runs locally on your Mac and opens in your browser. An optional native Mac wrapper can be built from source with Xcode command-line tools. This website is an introduction; it does not host the workspace or your libraries.

Does the download include production references?

No. It includes the reusable app, backend, and neutral starter resources. Your first launch creates an empty library. The artwork on this page is illustrative and not an included production library.

How do I protect and back up my work?

Stop the app and copy the complete working folder, including libraries and the hidden .state directory. Git ignores those private runtime folders, so pushing the framework to GitHub does not back up your production data. Linked libraries also need their original media folders.
