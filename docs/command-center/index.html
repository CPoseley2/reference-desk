01 / THE BIG PICTURE

Know what’s ready.
See what’s next.

An act-by-act Command Center brings storyboards, alternate versions, image coverage, and production briefs into one view.

COVERAGE / VERSIONS / NEXT STEPS

Make the next decision visible.

Open a selected storyboard, compare its available versions, and see missing image slots. Register your own JSON sources explicitly. Your source files stay separate from saved working decisions.

02 / DIRECTOR’S TOOLS

Every frame
has a reason.

Keep script context and visual direction beside the shot. Prepare the words and references that communicate your intent.

VIEWPOINT / FRAMING / MOVEMENT

Put intention into the prompt.

Choose camera and framing presets, edit the wording, and apply each direction independently. Plan start and end references, seam notes, and returned-clip feedback. With configured cast and location references, save those choices alongside each shot.

03 / THE IMAGE WORKSPACE

Find the image.
Feel the sequence.

Browse images, assign them to shots, swap positions, and compare the possibilities. Keep source imagery intact as your arrangement evolves.

SELECT / ARRANGE / APPROVE

A choice is more than a thumbnail.

Inspect image information and tags. Keep exact-image approval distinct from a working selection. Add images from your own files or a configured Reference Desk library, insert shots, and save the sequence you intend to use.

04 / CRESCENDO + CANVAS

Let the story
find its rhythm.

Review with audio and a canvas that docks, floats, or fills the screen. Keep playback moving while you work.

LISTEN / REVIEW / ADJUST

Put timing on the same desk.

Crescendo analyzes recordings with optional local audio dependencies. Storyboards configured for beat editing can adjust frame-based boundaries and review cut suggestions. Saved timing remains tied to the recording it was made for.

LISTEN / FIND THE MOMENT / REVIEW THE CUT

05 / A CLEARER REVIEW

Leave a note.
Keep the decision.

Flag the shots that need another look. Capture feedback without losing the context of the frame you were watching.

FLAGS / NOTES / HISTORY

Know what changed.

Shot flags use the sequence’s timing. Revision checks detect conflicting saves and retain drafts for review. Separate working selections, shot direction, and approvals help you revisit a decision without rewriting the original source.

06 / FINAL CUT XML

Take the sequence
into the edit.

Package the saved arrangement as an editable still-image timeline, with selected media and a manifest.

Read export requirements

PREFLIGHT / PACKAGE / IMPORT

An editorial starting point.

Choose saved timing and audio, or fixed clip durations. Preflight checks image selections, source changes, timing, and media access before packaging. Export needs ffmpeg, ffprobe, and Final Cut Pro’s XML definition on macOS. It produces FCPXML and media, rather than a rendered movie.

FROM THE REFERENCE DESK FOLDER

Connect your production.

python3 command-center/setup.py
python3 command-center/catalog.py add /path/to/storyboard.json
python3 command-center/launch.py

Python 3.11+ on macOS. Your local Command Center opens on port 8899. The setup guide includes the source format and optional connections.
