MACOS / PYTHON 3.11+

Set up once. Keep listening.

From the Reference Desk folder, run Set Up Crescendo.command to create its analysis environment. Launch Reference Desk, choose your library, and open Crescendo.

Analysis runs locally. It needs no OpenAI API key and does not send your recording to a cloud analysis service. The website is an introduction; your audio belongs in your local app.
